# Multiple Myeloma Drug Response Analysis

This repository contains the code used to investigate differences in the bone marrow immune microenvironment between different drug response groups in multiple myeloma, with a focus on patients treated with daratumumab and lenalidomide.

## Analysis Overview

The analysis includes:

* Single-cell RNA-seq data processing and quality control
* Characterization of the bone marrow immune microenvironment
* Comparison of immune cell populations between drug response groups
* Differential gene expression and pathway analysis
* Cell–cell communication analysis
* Validation of immune-related signatures

## Data

The data generated and analyzed in this study are available through the EMBL-EBI BioStudies database:

* **BioStudies accession:** S-BSST2098
* **Data link:** https://www.ebi.ac.uk/biostudies/studies/S-BSST2098
